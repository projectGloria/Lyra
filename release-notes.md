# Lyra v1.0.0 — The Lightweight Release 🎵

**Lyra** is a high-performance, zero-bloat music player designed for speed and simplicity. This release marks the first stable build of the application, featuring a refined UI and robust audio management.

### ✨ Key Features
*   **Vanilla Performance:** Built with pure JavaScript and CSS—no heavy frameworks, just raw speed.
*   **Spectrum Visualizer:** Real-time audio visualization with multiple modes (Dynamic, Vinyl, and Cover-focused).
*   **Smart Metadata:** Fast library scanning using `music-metadata` with lazy-loaded cover art to keep memory usage low.
*   **Global Integration:** Control your music from anywhere with global media keys and system tray support.
*   **Deep Customization:** Fully scriptable keybindings and themes via the `Lyra.cfg` system.

### 🛠️ Recent Improvements
*   **Volume Persistence:** The app now remembers your last volume setting automatically between sessions.
*   **Folder Toggling:** Added a new "Hide Playlists" mode to the queue, allowing you to filter your view to show only root tracks.
*   **EQ Status Pill:** A new interactive indicator in the titlebar shows your current Equalizer state (Preset/Custom) at a glance.
*   **UI Optimization:** Refined the settings layout and removed the redundant background "waves" from the carousel view for a cleaner aesthetic.
*   **Stability:** Fixed a critical syntax error that caused the application to become unresponsive on startup.

### 📦 Installation
1.  Download `Lyra Setup 1.0.0.exe` below.
2.  Run the installer.
3.  Launch Lyra and point it to your music folder!
